📤 EXPORT DATA (Backup)

Download all your roster, games, and stats as a backup file. Save this file to:

  • Your computer (Documents folder)
  • Google Drive or Dropbox
  • Email it to yourself
  • USB drive for safe keeping

💡 Recommended: Export after every game

📥 IMPORT DATA (Restore)

Restore data from a backup file. This will:

  • Replace ALL current data
  • Restore roster, games, and stats
  • Cannot be undone

⚠️ Warning: This will replace all your current data!

🗑️ CLEAR ALL DATA

Start fresh with a new season. This will permanently delete:

  • All games and stats
  • All roster data
  • All season history

⚠️ DANGER: This cannot be undone! Export first!

📅 IMPORT SCHEDULE FROM CALENDAR

Import games directly from a calendar file (.ics). Works with:

  • Google Calendar — Export from Settings → Import/Export
  • Apple Calendar — File → Export → Export...
  • Outlook — File → Save Calendar
  • Any .ics file from your league scheduler

💡 Tip: Events named "vs Pirates" or "@ Dodgers" will auto-detect the opponent.

Or paste a public calendar URL:

💡 Get URL from Google Calendar: Settings → Calendar → Integrate → Public URL (must be public)

📚 How This Works

Your data is stored on this device only. It doesn't automatically sync to other devices or the cloud. That's why backups are important! Export regularly and save your backup file somewhere safe.

To transfer to another device: Export on Device A → Email/Drive/USB → Import on Device B
